# Computer Architecture Practice Test

Practice for Computer Architecture Outcome 1. It covers binary and hex arithmetic, base conversions, two's complement, logic operators, ASCII and parity.

**Use it here:** https://snipeab.github.io/comp-arc-practice-test/

- **Original 20:** the questions from the class practice test.
- **New numbers:** the same 20 question types, with new random values every attempt.

Submit to see your score and a worked solution for every question.

## Run it locally

```bash
npm install
npm run dev
```

`npm test` checks the answer key.
